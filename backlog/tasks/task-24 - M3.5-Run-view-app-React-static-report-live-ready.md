## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The run view app: one React app that is both the end-of-run report and, later, the live view. Spec: `documentation/design/core.md`, "Run view: one app, one contract". It consumes the `RunView` contract from TASK-21.

## Files
- Create: `packages/lensgraph-ui/` (pnpm, React 18 + TypeScript, Vite, `vite-plugin-singlefile`, vitest + @testing-library/react, `@xyflow/react` + `@dagrejs/dagre` for the graph): `package.json`, `pnpm-lock.yaml`, `tsconfig.json`, `vite.config.ts`, `index.html`, `src/**`, `README.md`
- Create: `packages/lensgraph/src/lensgraph/view/app/index.html` (the **built** single-file bundle, committed) and `packages/lensgraph/src/lensgraph/view/app/BUILD_INFO.json` (source hash and build time)
- Modify: `packages/lensgraph/pyproject.toml` (package data for `view/app/*` if hatch needs it), `.gitignore` (`node_modules/`, `packages/lensgraph-ui/dist/`)
- Test: `packages/lensgraph-ui/src/**/*.test.tsx`; `packages/lensgraph/tests/test_view_app.py`
- Do not edit `src/types/run-view.ts` or `fixtures/toy-run.json` (generated by TASK-21's Python side).

## Interfaces
Consumes: `RunView` TS types (generated), `fixtures/toy-run.json`.

Produces:
```ts
// src/data/source.ts
export interface DataSource {
  load(): Promise<RunView>
  subscribe?(onEvent: (e: unknown) => void): () => void   // live sources only (TASK-23); typed then
}
export class EmbeddedSource implements DataSource          // reads window.__RUN__ (set by data/run.js)
export class FetchSource implements DataSource             // fetch(url) -> RunView (for served copies and tests)
export function pickSource(): DataSource                   // EmbeddedSource if window.__RUN__, else FetchSource("run.json")
```
```python
# lensgraph/view/__init__.py (Python helper)
def install_app(out_dir: Path) -> Path    # copies view/app/index.html into out_dir; returns its path
```
Semantics:
- **Pages** (hash routing, so it works on file://):
  - Run summary: status, timings, node counts, cache hits, LLM tokens and cost ("unknown" when null), and a candidate table (overall, direction, evidence share, agreement, per-lens status, review flags) that sorts by any column.
  - Plan graph: the stored `PlanGraph` in React Flow with a dagre layout, nodes coloured by status for the selected candidate, shared nodes marked, optional edges dashed; zoom and pan.
  - Candidate page: the dossier headline; per verdict: status, stance and stance_mean, conviction, coverage with input sufficiency, components, error, provenance; claims with each cite as a link that opens the cited value (table or JSON); "unresolved" shown for null cites; flags; the review (summary, fit with priority, gaps, flags).
- **State** lives in one store fed by the `DataSource`, so TASK-23 can apply events to the same store.
- **Safety:** never use `dangerouslySetInnerHTML`; all LLM text renders as text.
- **Build:** `pnpm build` yields one self-contained `dist/index.html`. A `pnpm bundle` script copies it to `packages/lensgraph/src/lensgraph/view/app/index.html` and writes `BUILD_INFO.json` with a hash of `src/**`, `package.json` and the lockfile.
- **Up-to-date check:** `test_view_app.py` recomputes the source hash and fails if `BUILD_INFO.json` is stale, so a UI change without a rebuild fails `uv run pytest`. The test needs no Node.
- **Python users never need Node:** only UI development does.
